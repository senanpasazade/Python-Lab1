# Python-Lab1
Python Mini Projects & Calculators

This repository contains a collection of simple Python scripts designed for basic calculations, fun interactive guessing games, and logic demonstrations.

Included Scripts

1. BMI Calculator (task1.py)

Description: Calculates the Body Mass Index (BMI) based on user-provided weight (in kilograms) and height (in meters).

Categories: Underweight, Normal weight, Overweight, and Obese.

Usage: Run the script and follow the prompts to enter your weight and height.

2. Chinese Zodiac Sign Finder (task2.py)

Description: Determines a person's Chinese Zodiac animal sign based on their birth year using the modulo operator (% 12).

Zodiac Animals: Monkey, Rooster, Dog, Pig, Rat, Ox, Tiger, Rabbit, Dragon, Snake, Horse, and Sheep.

Usage: Run the script and enter your birth year when prompted.

3. Birthday Guessing Game (task3.py)

Description: A clever binary number-trick program that guesses your birthday (day of the month, 1–31) by asking whether your number appears in five different sets.

Usage: Run the script and answer 1 for yes or 0 for no when asked if your number is present in each set.
